House Price Prediction 🏠

This project predicts house prices using Machine Learning.

Dataset

The dataset contains information about houses such as:

- Longitude
- Latitude
- Housing median age
- Total rooms
- Total bedrooms
- Population
- Households
- Median income

Machine Learning Model

A Random Forest model was used to predict house prices.

Results

- MAE: 32935.31
- RMSE: 50501.75
- R² Score: 0.815

The model achieved an R² score of approximately 81.5%.

Example Prediction

- Predicted house price: 136720.5
- Actual house price: 142700.0
